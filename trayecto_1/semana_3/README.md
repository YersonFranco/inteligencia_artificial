# Semana 3 — Ingeniería de prompts y evaluación básica

Diseñar instrucciones claras y reutilizables, y evaluar las respuestas con casos de prueba definidos.

La página explica los componentes de una instrucción, la diferencia entre zero-shot y few-shot, el uso de formatos de salida y los criterios para revisar respuestas. El contexto retoma el alcance y las fuentes del asistente definidos en la semana 1.

## Evidencias de aprendizaje

- Plantilla de prompt reutilizable.
- Cinco casos de prueba con respuestas esperadas, incluida una pregunta ambigua y una fuera de tema.
- Entregable del reto de Prompt Engineering: BiblioWeb, hecho con IA por el clan Orion ([aplicación](https://bibliowise-reading-companion.lovable.app/) y [repositorio](https://github.com/C8-Orion/biblioweb_ia)).

## Archivos de la actividad

- `plantilla_asistente.js`: plantilla con espacio `{pregunta}`, ejemplos few-shot y cinco casos con respuesta esperada.
- `material_consulta_clan.md`: información de referencia usada para formular los casos y revisar las respuestas.
