Semana 2

Cómo construye respuestas un modelo de lenguaje

Inteligencia artificial · Trayecto 1

¿Qué ocurre entre tu pregunta y la respuesta?

Un modelo de lenguaje no busca una respuesta completa dentro de una lista. Procesa el texto y va construyendo una continuación con la información que tiene disponible.

Aplicación y modelo son cosas distintas. El servicio es la aplicación con la que conversas; el modelo es el sistema que procesa tu solicitud. Un mismo servicio puede ofrecer varios modelos y herramientas, como búsqueda o lectura de archivos.

Del mensaje a una respuesta

LLM significa «modelo de lenguaje grande». Podemos imaginar su trabajo como un recorrido: cada etapa prepara la siguiente.

1

El texto se divide

El modelo separa lo que escribimos en tokens. Un token puede ser una palabra, una parte de ella o un signo. Por eso una palabra no siempre equivale a un token y los límites de uso suelen contarse en tokens.

2

Las piezas se convierten en números

Cada token se representa con números para que el modelo pueda procesarlo. También importa el orden: «el perro persigue al gato» no comunica lo mismo que «el gato persigue al perro».

3

El contexto ayuda a interpretar

La atención, una parte del Transformer, relaciona elementos del texto. Así, la palabra «banco» puede entenderse de forma distinta en «me senté en el banco» y «fui al banco a retirar dinero».

4

La respuesta se arma paso a paso

El modelo calcula qué tokens podrían continuar, elige uno y vuelve a calcular con el texto ampliado. Repite ese ciclo hasta completar la respuesta.

Una diferencia importante: esas probabilidades ayudan a elegir cómo continúa el texto; no indican qué tan verdadera es una afirmación. La temperatura puede cambiar la variedad de las respuestas, pero no garantiza que sean correctas.

Aprender el modelo y usarlo son momentos distintos

Entrenamiento

El modelo procesa muchísimos ejemplos y ajusta sus parámetros para aprender patrones. Es una etapa de construcción que requiere datos y capacidad de cómputo.

Inferencia

Es cuando usamos el modelo ya entrenado para responder. Darle una instrucción o un documento puede cambiar la respuesta de esa conversación, pero no significa que lo hayamos vuelto a entrenar.

El contexto también tiene un límite. El modelo trabaja con una cantidad máxima de texto: puede incluir tu pregunta, mensajes previos y documentos disponibles. Añadir más información no siempre ayuda; importa que sea relevante y clara.

Tres formas de describir un modelo

Estas expresiones hablan de aspectos diferentes. Un mismo modelo puede cumplir más de una descripción.

Fundacional

Es una base amplia que puede adaptarse a tareas distintas, como resumir, traducir o ayudar con código.

De frontera

Se considera entre los modelos más avanzados para ciertas capacidades. La etiqueta depende del momento y de la tarea que se compare.

De pesos abiertos

Sus parámetros entrenados están disponibles bajo ciertas condiciones. Eso no significa automáticamente que el código sea abierto ni que usarlo garantice privacidad.

Por ejemplo, usar un modelo mediante una página web o una API no permite concluir por sí solo si es de frontera. Para ejecutarlo en un equipo propio también hacen falta una licencia compatible y recursos suficientes.

Una idea que se investiga: el aprendizaje federado busca entrenar modelos usando datos que permanecen en distintos dispositivos. Es una forma de explorar la colaboración y la privacidad; no es una garantía automática de que los datos estén protegidos.

Lo que puede hacer y lo que debemos revisar

Puede ayudar a…

Explicar ideas, resumir textos, proponer borradores, traducir o sugerir código. Algunos modelos también reciben imágenes o audio; por eso se llaman multimodales.

Conviene comprobar…

Puede inventar datos o referencias, repetir sesgos y desconocer hechos posteriores a su fecha de entrenamiento. También puede responder diferente ante la misma pregunta.

Escribir no es ejecutar; responder no es buscar

Que una IA escriba código no prueba que lo haya ejecutado. Que mencione una fuente tampoco prueba que la haya consultado. Hay que revisar las herramientas usadas y comprobar el resultado.

Práctica: ordenar tres números con Python

El mismo principio de comparar y cambiar de lugar se puede convertir en un programa. Escribe tres enteros y ejecútalo aquí; el navegador carga Python para correr el algoritmo.

El intérprete Python se prepara al ejecutar el ejercicio.

El formulario ejecuta el mismo archivo ordenar.py que puedes descargar y correr en tu equipo.

La primera carga necesita internet para obtener Python en el navegador. Si abres los archivos desde tu equipo, usa un servidor local para que la página pueda cargar el archivo `.py`. Los números se procesan en el navegador.

La idea para llevar

Un modelo produce una continuación a partir del texto y el contexto disponibles. Puede ser útil, pero entender cómo llegó a su respuesta nos ayuda a pedir mejor y a verificar lo importante.
